# Contribution Guidelines

Thank you for your interest in contributing to awesome-free-browser-tools!

## What qualifies

- Tool is **free** with no mandatory signup for core functionality
- Tool runs **client-side** (all computation in browser, no data sent to server)
- Tool is **actively maintained** (no broken links, works in modern browsers)
- Tool is **genuinely useful** — not just another lorem ipsum generator

## What does not qualify

- Tools that require email signup before use
- Tools that upload your data to a server for processing
- Paywalled tools (free tier that blocks useful functionality)
- Tools that are just thin wrappers around a paid API

## Format

Add entries as table rows in the relevant category:

```
| [Tool Name](https://example.com/tool) | Clear one-sentence description of what it does | Source/Author |
```

Keep descriptions factual, not promotional. No "amazing", "best", "powerful" etc.

## Pull Request Process

1. Fork the repository
2. Add your tool to the correct category
3. Verify the tool works and meets the criteria above
4. Submit a pull request with a brief description of why this tool belongs here

## Code of Conduct

Be respectful and constructive. This list exists to help developers find quality tools, not to promote specific products. Maintain that spirit in all contributions.
